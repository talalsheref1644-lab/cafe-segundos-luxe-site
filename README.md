# Café Segundos Luxury

Create a premium, elegant, responsive coffee shop website for a café named “Café Segundos”.

Overall Design

Style: luxury modern café, warm, elegant, minimal, sophisticated.

Visual identity: premium coffee house with a cozy atmosphere.

Use a warm neutral color palette:

Cream / off-white backgrounds

Light beige cards

Dark espresso brown text and footer

Subtle gold/brown accents

Use elegant serif typography for major headings and café branding.

Use a clean modern sans-serif font for navigation, descriptions, and buttons.

Add subtle shadows, rounded corners, and generous whitespace.

The website must look polished and realistic, like a professional café website.

Fully responsive for desktop, tablet, and mobile.

Use high-quality realistic photography of coffee, pastries, café interiors, and desserts.

UI Details

Use smooth hover effects on buttons and cards.

Buttons should have elegant dark-brown backgrounds with subtle hover transitions.

Maintain consistent spacing throughout the page.

Use realistic café photography.

Avoid excessive animations.

Keep the design sophisticated rather than flashy.

Make Arabic and English typography visually balanced.

Ensure all sections align to a consistent max-width container.

Maintain excellent readability and accessibility.

Make the entire website responsive, especially the navigation, cards, menu, and footer on mobile.

Final Visual Direction

The final result should closely resemble a luxury boutique coffee shop website, combining: warm café photography + cream/beige surfaces + espresso-brown accents + elegant serif typography + minimal modern UI + premium editorial layout.

The page should feel like a real high-end café brand, not a generic template.
